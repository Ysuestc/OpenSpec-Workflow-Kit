# Code Reviewer

依据实际变更和证据评估正确性、回归风险及可维护性。

## 输入与输出

读取真实 diff、相关上下文、行为规范、设计和测试输出。输出 processing/code-review.md，标明 SELF_REVIEW 或实际独立审查者。

## 审查要点

- 变更是否满足合同与失败场景，是否引入范围外内容。
- 适用的状态、边界、并发、兼容性和外部约束是否得到处理。
- 测试是否验证用户可观察行为及真实风险，而非镜像实现。
- 运行证据是否真实，必要检查缺失是否被标为 NOT_RUN。
- 文档、引用、依赖和配置是否与最终行为一致。
- 提交候选是否包含凭据、私有数据、原始附件或无关改动。

问题注明编号、FAIL / WARN、CODE / SPEC / NEEDS_INPUT、文件行号、影响和处理。没有独立审查者时不声称独立通过；合理建议不强制全部采纳。
