# 项目上下文

此文件由接入项目填写。未填写的字段表示未知，不表示禁止用户已经明确要求的工作。先用当前用户请求和实际代码确认必要信息。

## 项目信息

- 项目名称：待填写。
- 项目目标与用户：待填写。
- 当前工程与已实现能力：待检查。
- 技术栈与架构约束：遵循实际项目，待填写。
- 本阶段范围与非目标：来自当前用户请求，待记录。

## 验证方式

- 必要测试、检查和运行命令：待填写。
- 集成验证环境与数据隔离：按实际风险填写。
- 无法运行的必要检查：注明原因与续跑条件。

## 授权与确认

- 当前请求和明确授权范围：待记录，不从模板继承。
- 需求或设计待决定问题：没有时写“无”。
- 提交、推送、部署和外部消息权限：未预授权；以当前用户明确指令为准。
- 交付分支与目标远程：待确认，不预设 main 或任何仓库地址。

## 时间与维护

- 日期与时区：优先使用用户或会话时区；缺失时使用 UTC 并标明。
- 相关规范和历史 change：按当前任务查找。
- 事实、建议、已确认决定分别记录；工作结束后只维护与项目相关的信息。
